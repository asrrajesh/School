HOW IT WORKS
================================================================================

USER WORKFLOW:
  1. Navigate: Academics → Generate Questions
  2. Select: Class → Subject → Chapter (must be pre-scanned)
  3. Configure: Question types, counts, marks in table
  4. Click: "GENERATE QUESTIONS" button
  5. Wait: 10-30 seconds (with loading indicator)
  6. Result: Success message + questions saved to MongoDB

SYSTEM FLOW:
  Frontend Form
       ↓
  Async Button Handler (validate, get user)
       ↓
  HTTP POST to Backend API
       ↓
  Backend (fetch chapter + call Claude AI)
       ↓
  Claude AI generates questions
       ↓
  Questions saved to MongoDB
       ↓
  Response back to UI
       ↓
  User sees: "✓ Generated N questions successfully!"
